# Barangay Assistance and Request System

A C#-based GUI application developed by **BINARY Group** as a Systems Architecture (SysArch) academic project.

## Project Overview

The **Barangay Assistance and Request System** is an academic software development project created as part of the Systems Architecture subject. This repository contains the project's source code and supporting resources.
